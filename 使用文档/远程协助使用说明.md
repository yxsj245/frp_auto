# 远程协助功能使用说明

## 功能概述

本项目基于 frp 改造为**远程协助专用系统**。核心流程为：

```
客户端申请端口穿透 → 服务端管理员审批 → 自动建立穿透通道 → 管理员可随时关闭
```

与原版 frp 的区别：
- 客户端**不能**通过配置文件直接创建代理穿透，所有穿透必须经过管理员审批
- 简化了操作流程，适合非技术人员使用

---

## 部署配置

### 服务端 (frps)

配置文件 `conf/frps.toml`：

```toml
bindPort = 7000

# 端口分配范围（审批通过后从此范围自动分配远端端口）
allowPorts = [{ start = 10000, end = 20000 }]

# Web 管理面板（管理员使用）
webServer.addr = "0.0.0.0"
webServer.port = 7500
webServer.user = "admin"
webServer.password = "admin"
```

启动命令：
```bash
./bin/frps -c ./conf/frps.toml
```

管理面板访问地址：`http://<服务器IP>:7500`

### 客户端 (frpc)

配置文件 `conf/frpc.toml`：

```toml
serverAddr = "服务器地址"
serverPort = 7000
auth.token = ""

# 可选：启用本地 Web 面板（无需密码）
webServer.addr = "127.0.0.1"
webServer.port = 7400
```

启动命令：
```bash
./bin/frpc -c ./conf/frpc.toml
```

客户端面板访问地址：`http://127.0.0.1:7400`

## 使用方式

### 方式一：命令行 (frpc apply)

适合脚本集成或快速使用：

```bash
# 基本用法 - 申请暴露本地 3389 端口（默认 TCP）
frpc apply -p 3389 --server 1.2.3.4 --server-port 7000

# 多端口 + 备注
frpc apply -p 3389,22 -r "张三的电脑，需要远程协助" --server 1.2.3.4 --server-port 7000

# 指定 UDP 协议
frpc apply -p 53 -t udp --server 1.2.3.4 --server-port 7000

# 同时映射 TCP 和 UDP（同一端口两种协议）
frpc apply -p 3389 -t tcp,udp --server 1.2.3.4 --server-port 7000

# 使用配置文件（不用每次指定 server）
frpc apply -c ./conf/frpc.toml -p 3389 -r "需要远程桌面协助"

# 启用 web 面板，监听在 0.0.0.0:7500
./frpc apply -p 22 --server 192.168.10.202 --server-port 7000 --web-port 7500 --web-addr 0.0.0.0

# 带认证的 web 面板
./frpc apply -p 22 --server 192.168.10.202 --server-port 7000 --web-port 7500 --web-user admin --web-pwd 123456
```

**参数说明：**

| 参数 | 缩写 | 说明 |
|------|------|------|
| `--ports` | `-p` | 要暴露的本地端口，多个用逗号分隔 |
| `--type` | `-t` | 协议类型，支持 tcp/udp，可同时指定多个（如 `-t tcp,udp`），默认 tcp |
| `--remark` | `-r` | 备注信息（会显示在管理面板中） |
| `--server` | | 服务器地址（覆盖配置文件） |
| `--server-port` | | 服务器端口（覆盖配置文件） |
| `--token` | | 认证 token（覆盖配置文件） |
| `--config` | `-c` | 配置文件路径 |

**输出格式（JSON Lines）：**

```jsonl
{"event":"applied","ports":[3389],"remark":"需要远程桌面协助"}
{"event":"approved","code":"ABC123","ports":[{"localPort":3389,"remotePort":10001,"remoteAddr":"1.2.3.4:10001"}]}
{"event":"closed","code":"ABC123"}
```

程序会保持运行直到连接被关闭或收到 Ctrl+C 信号。

### 方式二：Web 面板

1. 启动 frpc 并确保配置了 webServer
2. 打开浏览器访问 `http://127.0.0.1:7400`
3. 在"端口申请"页面填写：
   - 要暴露的端口（如 3389）
   - 备注信息
4. 点击提交，等待管理员审批

## 管理员操作（frps Web 面板）

访问 `http://<服务器IP>:7500`，使用配置的用户名密码登录。

### 审批流程

1. **查看申请列表**：首页显示所有客户端的穿透申请
   - 穿透码：唯一标识
   - 状态：待审批 / 已通过 / 已关闭
   - 在线状态：绿点=在线，灰点=离线
   - 备注：客户端填写的说明

2. **审批操作**：
   - 点击某一行打开详情弹窗
   - 查看备注和端口列表
   - 点击"同意全部"按钮批准

3. **审批通过后**：
   - 服务端自动分配远端端口（从 allowPorts 范围）
   - 客户端自动建立穿透通道
   - 详情中显示远端地址和端口

4. **关闭连接**：
   - 在已通过的申请详情中点击"关闭连接"
   - 或在列表操作列点击"关闭"按钮
   - 穿透通道立即断开

### 状态说明

| 状态 | 颜色 | 含义 |
|------|------|------|
| 待审批 (pending) | 橙色 | 客户端已申请，等待管理员操作 |
| 已通过 (approved) | 绿色 | 穿透已建立，正在使用中 |
| 已关闭 (closed) | 灰色 | 穿透已被管理员关闭 |

## 典型场景

### 远程桌面协助

1. 被协助方运行：
   ```bash
   frpc apply -p 3389 -r "李四的电脑，系统故障需要远程查看" --server xxx.xxx.xxx.xxx --server-port 7000
   ```

2. 管理员在面板审批通过

3. 协助方使用远程桌面连接：
   ```
   mstsc /v:服务器IP:分配的远端端口
   ```

4. 协助完成后，管理员在面板关闭连接

### SSH 远程运维

1. 被运维方运行：
   ```bash
   frpc apply -p 22 -r "生产服务器A，需要排查日志" --server xxx.xxx.xxx.xxx --server-port 7000
   ```

2. 管理员审批后，运维人员通过：
   ```bash
   ssh user@服务器IP -p 分配的远端端口
   ```

## 安全说明

1. **审批制**：所有穿透必须经管理员明确同意，杜绝未授权访问
2. **服务端强制校验**：即使绕过客户端直接发送代理请求，服务端也会拒绝未审批的代理
3. **端口范围限制**：通过 `allowPorts` 控制可分配端口范围
4. **管理面板认证**：frps 面板使用 HTTP Basic Auth 保护
5. **随时关闭**：管理员可随时关闭任何穿透连接

## 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 客户端连接失败 | 服务器地址/端口错误 | 检查 serverAddr 和 serverPort |
| 申请后无响应 | 管理员未审批 | 联系管理员在面板操作 |
| 审批后连接不通 | 本地端口未监听 | 确认本地服务已启动 |
| 面板打不开 | webServer 未配置 | 检查配置文件中 webServer 段 |
| 认证失败 | token 不匹配 | 确保客户端和服务端 auth.token 一致 |
