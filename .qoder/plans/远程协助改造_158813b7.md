# 远程协助改造计划

## 核心流程

```
客户端连接 frps → 发送端口申请(本地端口+备注) → 服务端生成穿透码并存储为 pending
→ 管理员在 frps 面板查看申请列表 → 点击同意 → 服务端发送 ApprovalNotify 给客户端
→ 客户端动态创建 TCP 代理并发送 NewProxy → 服务端自动分配远端端口并注册代理
→ 穿透建立 → 管理员可点击关闭 → 服务端关闭代理并通知客户端
```
所有 NewProxy 请求必须是已审批的协助代理，否则服务端直接拒绝。这样即使有人手动在 frpc.toml 写代理配置或使用旧版客户端，服务端也会拦截，确保只有通过审批流程才能建立穿透。

```go
// 客户端 → 服务端：端口申请
type PortApplication struct {
    Ports  []int  `json:"ports,omitempty"`   // 本地端口列表，如 [3389, 22]
    Remark string `json:"remark,omitempty"`  // 多行备注
}

// 服务端 → 客户端：申请响应
type PortApplicationResp struct {
    Code   string `json:"code,omitempty"`    // 穿透码
    Status string `json:"status,omitempty"`  // pending
    Error  string `json:"error,omitempty"`
}

// 服务端 → 客户端：审批通过通知
type ApprovalNotify struct {
    Code  string         `json:"code,omitempty"`
    Ports []ApprovedPort `json:"ports,omitempty"`
}

type ApprovedPort struct {
    ProxyName  string `json:"proxyName,omitempty"`  // assist-{code}-{index}
    LocalPort  int    `json:"localPort,omitempty"`
    RemotePort int    `json:"remotePort,omitempty"`  // 0=服务端自动分配
}

// 服务端 → 客户端：关闭协助通知
type CloseAssistance struct {
    Code   string `json:"code,omitempty"`
    Reason string `json:"reason,omitempty"`
}
```

在 `msgTypeMap` 中注册这 4 个类型。在 `pkg/msg/wire_v2.go` 中注册 V2 编解码（如果需要）。

## Task 2: 服务端协助管理器

**新建文件**: `server/assistance/manager.go`

核心数据结构：

```go
type Status string
const (
    StatusPending  Status = "pending"
    StatusApproved Status = "approved"
    StatusClosed   Status = "closed"
)

type PortRequest struct {
    LocalPort  int    `json:"localPort"`
    ProxyName  string `json:"proxyName"`   // assist-{code}-{i}
    RemotePort int    `json:"remotePort"`  // 审批后从 NewProxyResp 填充
    RemoteAddr string `json:"remoteAddr"`  // 完整远端地址
}

type Application struct {
    Code       string        `json:"code"`
    RunID      string        `json:"-"`       // 客户端 runID，用于查找 control 连接
    User       string        `json:"user"`
    ClientKey  string        `json:"clientKey"`  // 用于查询在线状态
    Ports      []PortRequest `json:"ports"`
    Remark     string        `json:"remark"`
    Status     Status        `json:"status"`
    CreatedAt  time.Time     `json:"createdAt"`
    ApprovedAt *time.Time    `json:"approvedAt,omitempty"`
    ClosedAt   *time.Time    `json:"closedAt,omitempty"`
}

type Manager struct {
    mu            sync.RWMutex
    applications  map[string]*Application  // code → application
    proxyIndex    map[string]string         // proxyName → code
}
```

方法：
- `CreateApplication(runID, user, clientKey, ports []int, remark string) *Application` — 生成随机码、代理名，存入 map
- `GetByCode(code string) (*Application, bool)`
- `ListAll() []Application`
- `Approve(code string) (*Application, error)` — 设状态为 approved
- `OnProxyRegistered(proxyName, remoteAddr string)` — 从 NewProxyResp 回填远端端口
- `Close(code string) (*Application, error)` — 设状态为 closed，返回 proxyName 列表
- `GetProxyNames(code string) []string` — 获取该码所有代理名
- `RemoveByRunID(runID string)` — 客户端断开时清理

func (ctl *Control) handleApprovalNotify(m msg.Message) {
    inMsg := m.(*msg.ApprovalNotify)
    // 为每个端口创建 TCPProxyConfig
    var cfgs []v1.ProxyConfigurer
    for _, p := range inMsg.Ports {
        cfg := &v1.TCPProxyConfig{
            ProxyBaseConfig: v1.ProxyBaseConfig{
                Name: p.ProxyName,
                Type: "tcp",
                ProxyBackend: v1.ProxyBackend{
                    LocalIP:   "127.0.0.1",
                    LocalPort: p.LocalPort,
                },
            },
            RemotePort: p.RemotePort, // 0 = 服务端自动分配
        }
        cfgs = append(cfgs, cfg)
    }
    // 合并到现有代理列表并更新
    ctl.addAssistanceProxies(inMsg.Code, cfgs)
}

## Task 7: CLI apply 子命令

**新建文件**: `cmd/frpc/sub/apply.go`

```go
var applyCmd = &cobra.Command{
    Use:   "apply",
    Short: "Apply for port forwarding (remote assistance)",
    RunE:  runApply,
}

var (
    applyPorts  []int
    applyRemark string
    applyServer string
    applyPort   int
    applyToken  string
)

func init() {
    applyCmd.Flags().IntSliceVarP(&applyPorts, "ports", "p", nil, "local ports to expose (e.g. 3389,22)")
    applyCmd.Flags().StringVarP(&applyRemark, "remark", "r", "", "remark for this application")
    applyCmd.Flags().StringVar(&applyServer, "server", "", "server address (overrides config)")
    applyCmd.Flags().IntVar(&applyPort, "server-port", 0, "server port (overrides config)")
    applyCmd.Flags().StringVar(&applyToken, "token", "", "auth token (overrides config)")
    rootCmd.AddCommand(applyCmd)
}
```

`runApply` 逻辑：
1. 加载连接配置（配置文件 + CLI 参数覆盖）
2. 启动 frpc Service（连接 frps）
3. 登录成功后调用 `svr.SubmitApplication(applyPorts, applyRemark)`
4. 输出 JSON 到 stdout（供外部程序解析）：
```json
{"event":"applied","code":"ABC123","status":"pending"}
```
5. 保持运行，监听状态变化：
   - 审批通过时输出：`{"event":"approved","code":"ABC123","ports":[{"localPort":3389,"remotePort":10001,"remoteAddr":"1.2.3.4:10001"}]}`
   - 关闭时输出：`{"event":"closed","code":"ABC123"}` 并退出
6. 支持 SIGINT/SIGTERM 优雅退出

在 `cmd/frpc/sub/root.go` 中注册 `applyCmd`。

## 关键设计决策

1. **端口分配**：客户端发送 NewProxy 时 `remotePort=0`，服务端通过现有 `ports.Manager.Acquire()` 自动分配。`allowPorts` 配置控制分配范围。

2. **代理命名**：`assist-{code}-{index}`，便于服务端按码查找和关闭代理。

3. **客户端在线状态**：复用现有 `server/registry/registry.go` 的 `ClientRegistry`，通过 `clientKey` 查询。

4. **保留协议基础设施**：不删除 `pkg/config/v1/proxy.go`、`server/proxy/*.go` 等文件，仅改变控制流。新流程默认创建 TCP 代理。

5. **CLI 输出格式**：JSON Lines（每行一个 JSON 对象），便于外部程序按行解析。stdout 输出事件，stderr 输出日志。

6. **frpc 认证移除**：当 `WebServerConfig.User` 和 `Password` 均为空时，不应用 auth 中间件。
